# Parcial 1 - Visitas Médicas

Este repositorio contiene dos aplicaciones independientes para la gestión de visitas médicas:

- **`visitas-medico-pwa`**: Versión Progressive Web App (React + Vite).
- **`visitas-medico-ionic`**: Versión Ionic React.

## 🚀 Instrucciones de Ejecución

### 1. Clonar el repositorio

```bash
git clone git@github.com:90sfranco/DESARROLLO_MOVIL.git
cd PARCIAL_1
```

---

### 2. Ejecutar Visitas Médicas PWA (`visitas-medico-pwa`)

```bash
cd visitas-medico-pwa
npm install
npm run dev
```

---

### 3. Ejecutar Visitas Médicas Ionic (`visitas-medico-ionic`)

```bash
cd visitas-medico-ionic
npm install
npm run dev
```
