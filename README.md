# Challenge 01 - Aplicación React

Este proyecto es una aplicación desarrollada con **React**

## Indicaciones de Uso

Sigue estos pasos para ejecutar el proyecto en tu equipo:

### 1. Instalar dependencias

Abre una terminal en la carpeta del proyecto y ejecuta:

```bash
npm install
```

### 2. Iniciar el servidor de desarrollo

Para ejecutar la aplicación localmente:

```bash
npm run dev
```

Una vez ejecutado, abre en tu navegador la dirección que se indica en la terminal.
