# Task Manager

Aplicación de Ionic y React para agregar, completar y eliminar tareas.

## Uso

Instalar Ionic CLI:

```bash
npm i -g @ionic/cli
```

Navegar a la carpeta raíz del proyecto & cambiar de rama:

```bash
cd DESARROLLO_MOVIL

git checkout challenge-03
```

Instalar las dependencias:

```bash
npm install
```

Iniciar el proyecto:

```bash
ionic serve
```
