# Demo Login

Aplicación de Ionic y React con una página de login y una página protegida.

## Uso

Instalar Ionic CLI:

```bash
npm i -g @ionic/cli
```

Navegar a la carpeta del proyecto & cambiar de rama:

```bash
cd DESARROLLO_MOVIL

git checkout challenge-04

```

Instalar las dependencias:

```bash
npm install
```

Iniciar el proyecto:

```bash
ionic serve
```
